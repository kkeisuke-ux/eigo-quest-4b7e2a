# えいごクエスト（eigo-quest）

iPad + Apple Pencil + Safari で使う、家族5人用の英語手書き学習PWA。
アルファベット（A〜Z / a〜z）→ 英単語 → 短い英文 → 「えいご絵日記」へと発展する。
学習の中心は **英単語を「聞く・見る・イメージと結びつける・実際に何度も書く」** こと。

かんじクエスト（`202608_kanji-quest`）の実証済み基盤（Apple Pencil入力・掌拒否・IndexedDB・
ゲームシステム・PWA）を土台に、英語版として新規開発した。**データ・ゲーム内容は完全に独立**
（DB名 `eigo-quest`、キャラクター・世界観も別物）。

---

## 1. 使い方（開発）

```bash
npm install
npm run dev        # 開発サーバー（PCで確認。マウスでも書ける）
npm run build      # 本番ビルド（tsc + vite + Service Worker生成）
npm run preview    # dist/ をローカル配信（ポート4174。使用中なら自動で次へ）
npm run gen:icons  # PWAアイコン再生成
npm run deploy     # GitHub Pages へ公開（リポジトリ eigo-quest-4b7e2a）
```

iPadでの利用: 公開URLをSafariで開き「ホーム画面に追加」→ フルスクリーンのPWAとして起動。
2回目以降はオフラインでも動作する（Service Workerが全アセットをキャッシュ）。

## 3. 認識エンジン

- 1文字 = 1ボックスに書き、テンプレートマッチング（DTW＋フレシェ＋Hungarian）で判定
- **box系**（4線ガイド上の位置・大きさ）と **shape系**（純粋な字形）の混合コスト
  → 大きさの帯で c/C などを区別しつつ、多少のズレ・傾きは許容
- 書き順・画の向きは不問（順序フリーのマッチング。仕様 §8, §14）
- O のような閉曲線は書き始めの位置もフリー（回転不変マッチング）
- 大文字と同形の小文字（c k o s u v w x z）は同じ文字として扱う
- しきい値は 設定 →「判定デバッグ」で実機調整・保存できる

ビルド版での自動テスト結果（`window.__eigoDev` 経由）:

| テスト | 結果 |
|---|---|
| 参照データ自身の分類（52文字） | 52/52 |
| ノイズ＋移動＋縮小拡大＋書き順逆転（156ケース） | 156/156 |
| 別の文字を書いたときの誤受理（120ケース） | 0件（全拒否） |
| 判定速度 | 約85ms/文字 |

## 4. 音声・音源

### 英語発音
- ブラウザ内蔵TTS（SpeechSynthesis）の **en-US音声をfeature detection**して使用
  （iPadではSamantha等の高品質音声を優先選択）
- 単語・アルファベットカードの表示と同時に自動発音、ボタンで何度でも聞き直せる
- 発音中はBGMが自動で下がり、終了後0.4秒かけて戻る（audio ducking。仕様 §35）
- `src/audio/tts.ts` の `PronunciationProvider` に実装を追加すれば、
  将来 `public/audio/voice/` の録音ファイルへ差し替えられる構造

## 6. 設計上の仮定（仕様 §68「合理的な仮定はREADMEへ記録」）

1. **単語筆記は「1文字=1ボックス」方式**。仕様§16の「1文字ずつ認識→結合→比較」を
   確実に実装でき、幼児にも書きやすい（マス数が答えの文字数のヒントになるのは意図的な足場）。
2. **イラストはMVPでは絵文字**（1〜2個の組み合わせ）。「シンプル・明るい・幼すぎない」を
   満たしつつ全120語に即日対応するため。データ構造（`WordIllustration`）は画像差し替え可能。
   曜日は日本語の曜日連想（🔥📅=火曜 など）で覚えやすくした。
3. **アルファベットなぞりは1文字2ラウンド**（ガイド付き→薄字のみ）。テンポ重視（仕様§1）。
4. **書き順は日本の学校で一般的なブロック体の書き方に準拠**（複数の流儀があるため、
   テストでは書き順を問わず「読める字形か」だけを判定。仕様§8どおり）。
5. **絵日記の手書き英文認識は「下読み」**。x座標クラスタリング＋文字分類で推定し、
   本人が読み取り結果を確認・修正してから添削する（自由筆記の完全認識は現実的でないため）。
6. **英文添削はオフラインのルールベース**（スペル距離・文頭大文字・I・ピリオド・be動詞・
   go to the・過去形）。仕様§30の例（i go park yesterday → I went to the park yesterday.）に対応。
   構造は差し替え可能で、将来LLM API等の高精度添削を追加できる。
7. **PDF出力は印刷ダイアログ経由**（外部ライブラリなし・オフライン動作）。iPadのSafariでは
   印刷プレビューをピンチアウト → 共有 → 「"ファイル"に保存」でPDFになる。
8. **絵日記の線の強弱（筆圧）は保存しない**（保存容量対策。色・太さ2種は保存する）。
9. 学年選択に「ようじ」を追加（grade=0）。単語レベルは学年と独立に全員が全レベルを学べる
   （まとめテストのレベル表示は「小1相当」等。公式配当とは表現しない。仕様§25）。
10. 連続学習ボーナス（仕様§40）: 前日も学習した日の最初の学習で +streakBonus コイン（1日1回）。

## 8. 主要な操作フロー

- **アルファベット**: ホーム → アルファベット → 文字タップ（そこから練習）or テスト。
  テストは「文字名を聞いて書く」。読める字形なら正解、正解で習得数が増える（26文字別管理）。
- **単語**: ホーム → たんご → ステージの「れんしゅう」（4ステップ×5語・途中保存）→「5もんテスト」。
  テスト正解で「おぼえたたんご」に加算、わからない/不正解は復習リストへ（テスト正解で自動卒業）。
- **まとめテスト**: ホーム → まとめテスト。学期の全20語連続・1問ごと自動保存・最高点更新。
- **絵日記**: ホーム → えいご絵日記 → きょうのにっき。絵（8色ペン）＋英文手書き →
  「かいた字をよみとる」→ 確認・修正 → 「えいぶんをチェック」→ 保存 / PDF。
- **ゲーム**: 学習でコイン → ガチャ（外れあり・天井3回・初回確定）/ スター購入 → バディ育成 →
  レベルアップ → 進化（次の姿は事前に見せない）→ 図鑑。

## 9. 既知の制限・今後

- 絵日記の手書き英文認識は文字が離れて丁寧に書かれている場合に有効（続け字は不可）
- 英文練習モード（お手本例文の書き写し。sentences.ts）は画面未実装（データのみ）
- 実機（iPad + Apple Pencil）でのしきい値調整を推奨: 設定 → 判定デバッグで
  子どもの実筆記にラベルを付けて調整できる
